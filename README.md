## What This Pattern Provides

- GitOps deployment via ArgoCD
- Operator lifecycle management (cert-manager Operator for Red Hat OpenShift, Red Hat OpenShift AI, OpenShift Pipelines, OpenShift Serverless, OpenShift Service Mesh)
- HashiCorp Vault secret management
- Multi-cloud support (AWS, Azure, GCP, IBM Cloud)

## Deploy

```bash
# Clone and deploy
oc login <cluster>
./pattern.sh make install
```

The pattern must be on a git remote accessible by the cluster. If starting from a local copy, push it to a git repo first.
